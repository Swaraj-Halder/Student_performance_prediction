# Student Performance Prediction and Academic Risk Analysis — SEC C

A simple MCA/student mini-project built with Python, Pandas, Scikit-learn and Streamlit.

## Project objectives

- Predict future/final examination marks using **Linear Regression**.
- Predict **Pass / Fail** and pass probability using **Logistic Regression**.
- Find students with similar academic profiles using **K-Nearest Neighbors (KNN)**.
- Group students into **At-Risk, Average and High Performing** segments using **K-Means**.
- Display academic risk (Low, Medium or High) and basic dataset analysis.

## Features used

| Feature | Description |
|---|---|
| `attendance` | Attendance percentage (0–100) |
| `study_hours` | Average daily study hours |
| `previous_marks` | Previous examination marks (0–100) |
| `assignment_marks` | Assignment marks (0–100) |
| `internal_marks` | Internal assessment marks (0–100) |
| `final_exam_marks` | Final examination marks / target |

The included dataset is **synthetic demonstration data**, generated by `generate_data.py`. It is not real institutional student data. Replace it with approved, anonymized data for a real academic study.

## Run in VS Code (Windows)

### 1. Open the project

Extract the ZIP and open the project folder in VS Code.

### 2. Create and activate a virtual environment

Open **Terminal → New Terminal**:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Generate the sample dataset

```bash
python generate_data.py
```

This creates `data/student_performance.csv`.

### 5. Train the machine-learning models

```bash
python train.py
```

This performs data cleaning, train/test splitting, five-fold cross-validation and saves the trained model bundle and metrics under `models/`.

### 6. Start the Streamlit dashboard

```bash
streamlit run app.py
```

Open the local URL shown in the terminal, usually `http://localhost:8501`.

## Use your own dataset

Prepare a CSV with these columns:

```text
attendance,study_hours,previous_marks,assignment_marks,internal_marks,final_exam_marks
```

For training on your own data, replace `data/student_performance.csv` with your approved dataset, keeping the required column names, then run:

```bash
python train.py
```

Do not upload personally identifiable student data to a public GitHub repository. Use synthetic or anonymized data.

## Methodology and interpretation

- Missing numeric values are filled using the column median and duplicate rows are removed.
- Linear Regression is evaluated with MAE, RMSE and R².
- Logistic Regression is evaluated with accuracy, precision, recall, F1 and ROC-AUC.
- Five-fold cross-validation is used for regression and classification evaluation.
- KNN uses standardized feature values to find similar profiles.
- K-Means uses standardized features; cluster names are assigned by ranking each cluster's mean final mark.
- The pass threshold is set to 40 marks in this demonstration. Change it to match the institution's official grading rules.

## Limitations

This is a learning prototype, not an official grading or student-selection tool. Synthetic data can demonstrate the workflow but cannot establish real-world predictive accuracy. Predictions should support constructive intervention, not label or penalize students.
